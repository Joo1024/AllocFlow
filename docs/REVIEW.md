## 已修正

- 清仓费用先计入净值，再赎回基金份额，防止清空账户后残留份额造成虚假的-100% TWR。
- 延迟买单保留预算，延迟卖单保留库存；提款和其他规则不可挪用。
- 情景价格遵守各资产交易日历；基金净值保留延后可见时间。
- 文件快照导出时携带原始字节，保持dataset_id；内存数据明确标识没有内嵌文件。
- XIRR多根搜索去重容差与残差容差均公开配置，不将非传统现金流的单个候选根视为唯一解。
- 现金计息与XIRR日计数规则显式配置，策略上下文不能看到执行日价格。

## 验证方法

经济测试采用独立手算、不变式、属性测试、未来数据扰动和中途续跑比较。
覆盖六个模板、初始/后续分池、固定/比例/max费用、提款拒绝回滚、预算保护、现金归零、
串行/并行同路径、配置错误定位、快照哈希、Decimal导出与Streamlit模板载入。
合成样例已运行三年；中国资产与退休提款另行运行。数据是合成路径，不是收益承诺。

## 公开限制

- Web 当前以完整YAML编辑为主，尚未为每个字段提供独立表单控件。
- 真实行情下载接口尚未作为端到端历史数据认证；核心测试均离线运行。
- 场外基金为可见净值延迟模型，真实申赎和到账日历尚需独立执行适配器。
- 同日跨市场按日级顺序建模；没有盘中成交、交易税、税务批次、原价公司行动。
- 再平衡先卖后买，费用/数量步长/休市可能留下偏差；事件保留每笔拒绝与未成交意图。
- 情景失败单独列出；成功路径的耗尽比例是条件统计，不冒充全部路径的概率。

# 财务逻辑 Review 修复

针对 98532a4 的审查问题，本轮修复覆盖预算、再平衡、恢复、比较、指标区间、零权重、滚动高点和 MarketData 接口。

## 预算与执行

PolicyContext 保留 budgets 作为可用金额兼容接口，新增不可变 BudgetSnapshot，分别提供 balance、pending、reserve、spendable。budget_inclusive 使用完整余额；可参与投资的预算仅扣除可花部分，保留挂单和储备的配置归属。零权重节点不做除法，其现金保持未部署，不捏造证券权重。

再平衡先发卖单，再发 FundedBuyIntent。调度器逐笔读取真实可用余额，按配置顺序分配预算，成交或挂单后才扣减剩余资金需求。卖出尚未成交的预期收入不能使用；拒绝的买单不占用后续预算。不同预算分笔成交仍按各笔收取费用。剩余未部署额写入 funding 事件。

## 检查点

新检查点版本为 2，身份契约覆盖资产 symbol、kind、currency、calendar、price_mode、pricing、quantity_step，以及报告币种和预算币种。文件恢复和 SDK initial_state 均校验。后续规则、目标配置及费用仍可显式变更。

旧版本 1 缺少足够的资产身份信息，不能安全推断；明确报错，需使用原计划和固定快照重新运行生成 v2 检查点，不做静默升级。

## 比较与指标

严格比较校验现金流规格、决策日历、阶段启用、通胀、提款政策/上下限、受保护储备；运行后再次核对实际现金流。比例提款或资金不足导致实际流不同，也拒绝按“同现金流”比较。require_same_cashflows=False 可显式查看不同资金路径。

顶层指标统一表示本次运行窗口：盈亏扣除期初财富，XIRR 将期初财富视为窗口期初投入。scope 给出起止与期初财富；since_inception 单列累计净投入、现金盈亏和 XIRR。Web/HTML 的净投入曲线标明“本窗口”，不再暗示包含检查点以前的投入。

## 信号与数据接口

new_peak 要求当前可见高点严格高于最后一次触发高点；滚动窗口移出旧高点不会重新解锁。

MarketData 完整定义 metadata、价格/FX/历史查询、观测序列、币种列表、staleness policy 克隆与导出接口。应用服务、预检和情景只使用这些公开接口；不再修改传入对象或依赖 prices/rates 私有结构。使用仅实现协议、且禁止新增属性的适配器做回归。

## 验证

新增手算用例覆盖：空到账预算回退、多标的预算占用、实际卖出收入、储备/挂单归属、零权重、文件与内存恢复身份变化、滚动高点、现金流政策与实际金额差异、续跑指标和替代数据适配器。

执行环境本轮不可用，测试与静态检查通过 GitHub Actions 执行；CI 记录为最终证据。旧真实数据结果不视为修复后的验收值，重新回放结果另行记录。
